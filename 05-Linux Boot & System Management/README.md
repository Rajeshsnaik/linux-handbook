# Day 5 — Linux Boot & System Management

> **Linux & DevOps Learning Journey — Day 5**

![Linux Boot & System Management](./Day%205.png)

Today we covered essential **Linux boot and system management concepts** used to understand the Linux startup process, manage services, troubleshoot kernel and hardware issues, monitor servers, and strengthen system security.

---

## What We Covered Today

| Topic                  | GitHub Repository                                 | What We Covered                                                                                                                                                                |
| ---------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Linux Boot Process** | [`Linux Boot Process`](./Linux%20Boot%20Process/) | Understanding the Linux boot sequence from BIOS/UEFI and bootloader initialization to kernel loading, `initramfs`, systemd, services, and reaching the final target.           |
| **`systemctl`**        | [`systemctl`](./systemctl/)                       | Managing systemd services using commands such as `start`, `stop`, `restart`, `reload`, `enable`, `disable`, `mask`, and checking service status.                               |
| **`dmesg`**            | [`dmesg`](./dmesg/)                               | Viewing kernel-related messages from the kernel ring buffer and troubleshooting hardware, drivers, disks, USB devices, networking, boot issues, and kernel errors.             |

| **SELinux**            | [`SELinux`](./SELinux/)                           | Understanding Security-Enhanced Linux, Mandatory Access Control (MAC), SELinux modes, security contexts, file labeling, `getenforce`, `setenforce`, `ls -Z`, and `restorecon`. |

---

## Key Takeaways

By the end of Day 5, we understood:

- The complete **Linux boot process**, from BIOS/UEFI to systemd and system services.
- The role of the **bootloader, Linux kernel, initramfs, and systemd**.
- How to manage Linux services using **`systemctl`**.
- The difference between **starting, stopping, restarting, reloading, enabling, disabling, and masking** services.
- How to use **`dmesg`** to investigate kernel, hardware, driver, and boot-related issues.
- How **Cockpit** provides a web-based interface for Linux server administration and monitoring.
- What **SELinux** is and how it provides an additional security layer through Mandatory Access Control.
- The difference between **Enforcing, Permissive, and Disabled** SELinux modes.
- How SELinux **security contexts and labels** control access to resources.
- How these concepts are useful for **Linux administration, server management, security, troubleshooting, and DevOps tasks**.
