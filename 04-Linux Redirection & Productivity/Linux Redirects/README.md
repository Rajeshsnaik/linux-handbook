# Linux Redirects | Standard Input (stdin), Standard Output (stdout), Standard Error (stderr)

## What is Redirection in Linux?

**Redirection** is the process of changing where a command receives its input or sends its output. By default, commands read input from the keyboard and display output on the terminal, but redirection allows you to use files instead.

There are **three standard streams** in Linux:

- **stdin (0)** – Standard Input
- **stdout (1)** – Standard Output
- **stderr (2)** – Standard Error

---

## Standard Input (stdin)

**stdin** is the default input source for a command. Normally, it comes from the keyboard, but it can also be redirected from a file using the **`<`** operator.

### Syntax

```bash
command < input_file
```

### Example

```bash
sort < names.txt
```

The `sort` command reads data from `names.txt` instead of the keyboard.

---

## Standard Output (stdout)

**stdout** is the normal output produced by a command. By default, it is displayed on the terminal. Use the **`>`** operator to save it to a file.

### Syntax

```bash
command > output_file
```

### Example

```bash
ls -l > files.txt
```

The output is written to `files.txt`. If the file already exists, it is overwritten.

---

## Standard Error (stderr)

**stderr** contains error messages generated by a command. It is separate from normal output.

### Syntax

```bash
command 2> error_file
```

### Example

```bash
ls unknownfile 2> error.log
```

The error message is saved to `error.log`.

---

## Types of Redirection

| Operator | Description                         |
| -------- | ----------------------------------- |
| `>`      | Redirect stdout (overwrite)         |
| `>>`     | Redirect stdout (append)            |
| `<`      | Redirect stdin                      |
| `2>`     | Redirect stderr                     |
| `2>>`    | Append stderr                       |
| `&>`     | Redirect stdout and stderr together |
| `2>&1`   | Send stderr to stdout               |

---

## Combine Multiple Files

Use the **`cat`** command.

```bash
cat file1.txt file2.txt > combined.txt
```

Creates `combined.txt` containing both files.

Display combined output without creating a file:

```bash
cat file1.txt file2.txt
```

---

## Save Command Output to a File

Redirect standard output:

```bash
date > today.txt
```

Another example:

```bash
df -h > disk_usage.txt
```

---

## Append Output to a File

Use **`>>`** instead of `>`.

```bash
date >> logfile.txt
```

The new output is added to the end of the file instead of replacing its contents.

---

## Redirect Errors to a File

```bash
find /root -name "*.log" 2> errors.log
```

Only error messages are saved.

---

## Save Both Output and Errors

```bash
find / -name "*.conf" > output.txt 2> errors.txt
```

This stores normal output and errors in separate files.

---

## Save Output and Errors Together

```bash
find / -name "*.conf" > result.txt 2>&1
```

Or use the shorter syntax:

```bash
find / -name "*.conf" &> result.txt
```

Both normal output and error messages are written to the same file.

---

## Ignore Error Messages

Redirect errors to `/dev/null`.

```bash
find / -name "*.log" 2> /dev/null
```

This is useful for hiding permission errors during searches.

---

## Read Input from a File

```bash
wc -l < names.txt
```

Counts the number of lines in `names.txt`.

---

## How Redirection Works

```text
             Keyboard
                │
                ▼
           stdin (0)
                │
                ▼
            Command
          /         \
         /           \
stdout (1)        stderr (2)
     │                 │
     ▼                 ▼
Terminal/File     Terminal/File
```

## Common Use Cases

- Save command output to log files
- Append application logs
- Combine multiple files
- Ignore unwanted error messages
- Read input from files
- Generate reports
- Automate shell scripts
- Capture troubleshooting logs

---

## Why Redirection is Important

Redirection is one of the most fundamental Linux features. It allows commands to read input from files, save output for later use, capture errors separately, and chain commands together.

Mastering **stdin**, **stdout**, **stderr**, and redirection operators is essential for:

- Linux Administration
- Shell Scripting
- DevOps
- Cloud Engineering
- Automation
- Troubleshooting
