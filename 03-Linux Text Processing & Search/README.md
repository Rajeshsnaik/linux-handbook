# Day 3 — Linux Text Processing & Search

> **Linux & DevOps Learning Journey — Day 3**

![Linux Text Processing & Search](./Day%203.png)

Today we covered essential **Linux text processing and search commands** used to search, filter, process, and work with data from files, command output, logs, and other sources.

---

## What We Covered Today

| Topic                                             | GitHub Repository                                                       | What We Covered                                                                                                                                                                                                      |
| ------------------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`grep`**                                        | [`grep`](./GREP/)                                                       | Searching for specific text or patterns inside files and command output, using options for case-insensitive searches, line numbers, recursive searches, and pattern matching.                                        |
| **Pipe, `tee`, `xargs`**                          | [Pipe, tee & xargs](./Pipe,%20TEE,%20XARGS/)                            | Using pipes `\|` to connect commands, `tee` to display and save command output simultaneously, and `xargs` to pass command output as arguments to another command.                                                   |
| **`pgrep`, `egrep`, `fgrep`, `zgrep`, `pdfgrep`** | [Linux Search Commands](./PGREP,%20FGREP,%20ZGREP,%20PDFGREP,%20EGREP/) | Searching running processes with `pgrep`, extended pattern matching with `egrep`, fixed-string searching with `fgrep`, searching compressed files with `zgrep`, and searching text inside PDF files using `pdfgrep`. |
| **`cut`**                                         | [`cut`](./cut/)                                                         | Extracting specific columns, fields, characters, and sections of text from files and command output using delimiters and different `cut` options.                                                                    |

---

## Key Takeaways

By the end of Day 3, we understood:

- How to search text and patterns using **`grep`**.
- How to combine multiple Linux commands using **pipes (`|`)**.
- How to use **`tee`** to save and display command output at the same time.
- How **`xargs`** converts input into command arguments.
- How to search running processes using **`pgrep`**.
- How **`egrep`** and **`fgrep`** are used for different types of pattern matching.
- How **`zgrep`** can search compressed files without manually extracting them.
- How **`pdfgrep`** can search text inside PDF documents.
- How to extract specific fields and columns using **`cut`**.
- How these commands are useful for **log analysis, troubleshooting, automation, and DevOps tasks**.
