# Day 6 — Processes & Process Management

> **Linux & DevOps Learning Journey — Day 6**

![Linux Process Monitoring & Management](./Day%206.png)

Today we covered essential **Linux process monitoring and management concepts** used to understand running processes, monitor CPU and memory usage, troubleshoot applications, identify processes, and manage processes effectively.

---

## What We Covered Today

| Topic                  | GitHub Repository                               | What We Covered                                                                                                                                                            |
| ---------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ps`**               | [`ps`](./ps/)                                   | Understanding the `ps` command for viewing a snapshot of running processes, checking PIDs, PPIDs, users, CPU time, process states, and command information.                |
| **`top`**              | [`top`](./top/)                                 | Monitoring running processes in real time, including CPU usage, memory usage, load average, process states, and system resource consumption.                               |
| **Process Management** | [`Process Management`](./process%20management/) | Understanding process lifecycle and managing processes using signals, PIDs, foreground/background execution, and commands such as `kill`, `pkill`, `jobs`, `bg`, and `fg`. |
| **`pgrep`**            | [`pgrep`](./pgrep/)                             | Finding processes by name or other attributes and retrieving their PIDs, with options for matching users, displaying process names, and identifying specific processes.    |

---

## Key Takeaways

By the end of Day 6, we understood:

- How Linux **processes** work and why every running process has a unique **PID**.

- How to use **`ps`** to get a snapshot of currently running processes.

- The difference between **`ps` and `top`**, and when to use each command.

- How to use **`top`** for real-time monitoring of CPU, memory, load average, and running processes.

- How to identify important process information such as **PID, PPID, user, CPU usage, memory usage, process state, and command**.

- How to manage processes using **signals and process-management commands**.

- The difference between **foreground and background processes**.

- How to find specific processes using **`pgrep`**.

- How process monitoring helps with **Linux troubleshooting, performance analysis, application debugging, and server administration**.

- How these concepts are useful for **Linux administration, DevOps, cloud infrastructure, and production server troubleshooting**.
